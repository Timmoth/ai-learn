A new Mac is one of those tools that feels great out of the box and quietly gets faster the more you learn about it. macOS hides a lot of its best behaviour behind keyboard shortcuts, trackpad gestures, and a handful of System Settings toggles that ship turned off. None of it is hard. It just isn't obvious. This lesson is the tour you wish someone had given you on day one.

We will cover the keyboard shortcuts that pay back the most per minute of learning, the trackpad gestures that make moving around feel effortless, how to use Spotlight as your launcher and personal calculator, how to manage windows with Mission Control and the new tiling system, the System Settings worth changing first, and a handful of Finder tricks that turn it from "the thing files live in" into a real navigation tool.

Before anything else, let's talk about the modifier keys. Mac shortcuts use four main modifiers. Command is the workhorse — it is the rough equivalent of Control on Windows. Option is the next one over, sometimes labelled "alt". Control exists too, but it is used less often than on Windows. And Shift, of course, is Shift. There is also a function key, usually bottom-left, marked fn. When we say a shortcut like Shift Command 5, we mean hold down Shift and Command first, then tap 5.

Now let's go through the shortcuts that earn their keep. These work in almost every Mac app. Command C, Command V, and Command X are copy, paste, and cut. Command Z is undo, and Shift Command Z is redo. Command S saves. Command A selects all. Command F finds text in the current document or page. Command W closes the current window or tab, and Command Q quits the entire app. Command Tab switches between running apps, like Alt Tab on Windows. Command with the backtick key — that's the key just above Tab — cycles between windows of the current app. Command H hides the current app. Command M minimises the window to the Dock. Command Space opens Spotlight. Shift Command 5 brings up the screenshot and screen recording tool. Option Command Escape opens the force-quit picker, which is the Mac's equivalent of Task Manager. And Control Command Q locks the screen instantly.

There is one subtle thing here that catches almost everyone coming from Windows. On a Mac, closing the last window does not quit the app. The app is still running in the menu bar at the top of the screen. Command Q is what actually quits it. Worth getting in the habit of.

Let's spend a moment on screenshots. Shift Command 5 opens a small toolbar at the bottom of the screen with everything you need — full screen capture, window capture, region capture, screen recording, and a timer. There are also direct shortcuts. Shift Command 3 captures the whole screen. Shift Command 4 lets you drag a region, and if you press Space mid-drag it switches into window mode and gives you a clean window screenshot with a nice drop shadow. If you hold Control with any of these, the screenshot goes to your clipboard instead of being saved as a file to the desktop.

Next, let's talk about trackpad gestures. The Mac trackpad is the part of the machine most worth learning gestures for. Apple has spent twenty years making it the best in the industry, and gestures are how you unlock it. Open System Settings, then Trackpad, and you'll see every gesture animated in a little video clip — it is genuinely the most useful settings page on the machine.

Here are the highlights. With two fingers, you scroll up or down. You pinch to zoom on photos, PDFs, and web pages. A two-finger tap is right-click, which Apple calls "secondary click". Swipe left or right with two fingers to go back and forward in Safari, Finder, and most native apps. And swiping in from the right edge with two fingers opens Notification Center.

With three fingers, tap on any word to look it up in the dictionary. Even better, you can enable something called three-finger drag, hidden in System Settings under Accessibility, then Pointer Control, then Trackpad Options. With three-finger drag turned on you can move windows and select text just by sliding three fingers across the trackpad — no clicking required. Once you have used it for a day, going back feels broken.

With four fingers, swipe up to open Mission Control, which is an overview of every open window. Swipe down for App Exposé, which shows every window of the current app. Swipe left or right to move between full-screen apps and virtual desktops. And if you pinch with thumb and three fingers you get Launchpad, while spreading the same fingers shows the desktop.

Now, Spotlight. Command Space opens Spotlight, and most people learn it as "the way to launch apps without leaving the keyboard", which is true, but it does so much more. Type a few letters of an app name and hit Return — done. Type initials, like ST for Sublime Text, and it will find the app for you, then learn which one you actually wanted so it ranks it higher next time.

But Spotlight is also a calculator. Type 1450 times 1.2 and it shows 1740 inline. It does currency and unit conversion — 50 USD in EUR, or 12 stone in kilograms. Type "define" followed by a word for a dictionary definition. Type "weather london" for a forecast. Type a file name to find files, and you can filter by file type using kind colon — for example, "kind colon pdf budget" finds PDFs with "budget" in the name.

A few habits will make Spotlight pay off. When a result is highlighted, hold Command to see the full path of the file underneath, and press Command Return to reveal the file in Finder instead of opening it. And if you want to trim the noise, open System Settings, then Spotlight, and turn off categories you never use, like Mail messages or Siri Suggestions. There is also a Privacy tab where you can exclude folders entirely from indexing.

Let's move on to window management. macOS gives you three different lenses on your open windows, and they sound similar but solve different problems. The first is Mission Control. Press F3 or do a four-finger swipe up, and you get a zoomed-out view of every window on every desktop. Click any window to jump to it. Drag a window to the top of the screen to send it to a new virtual desktop.

The second is Spaces, which is what macOS calls those virtual desktops. Each Space is a separate canvas, and any full-screen app gets its own Space automatically. Switch between them with Control and the left or right arrow, or swipe left or right with four fingers on the trackpad. A useful pattern is one Space for communication apps like Mail and Slack, one for the work you are focused on, and one full-screen for video calls.

The third option, Stage Manager, is newer and off by default. Turn it on from Control Center — that's the icon in the menu bar that looks like two sliders — or in System Settings under Desktop and Dock. Stage Manager keeps the window you are using in the centre of the screen and parks the rest as small thumbnails on the left. Click a thumbnail to swap in that app. You can drag a thumbnail into the centre to group apps together so they come back as a set. It's a great fit for people who like a focused, single-task workspace. Less so if you rely on having many windows visible at once. You do not need to use all three. Most people pick a primary mode and ignore the others.

Now, native window tiling. macOS Sequoia, which came out in 2024, finally added the snap-to-edge tiling that Windows has had for years. There are three ways to use it. The first is to drag a window to an edge — top, left, right, or a corner — and a translucent preview shows where it will snap. Release to drop it in. The second is to hover your pointer over the green traffic-light button at the top-left of any window. A menu appears with layout options like left half, right half, top and bottom halves, quarters, and the classic full screen. And the third is keyboard shortcuts. Fn Control Left Arrow snaps the active window to the left half. Right, up, and down arrows do the obvious equivalents. Fn Control F fills the screen without going into full-screen mode, which is useful when you want a maximised window but still want to see the menu bar.

If you prefer the old behaviour, where dragging a window does not tile it, you can hold Option while dragging to suppress the snap.

Let's turn to Finder, which is the file browser. Like everything else on macOS, Finder gets faster the more shortcuts you use. Command N opens a new Finder window. Command T opens a new tab — Finder has browser-style tabs, which is great. Shift Command N makes a new folder. Control Command N makes a new folder from the currently selected files, which is perfect for tidying up your Downloads folder. Command 1, 2, 3, and 4 switch between icon, list, column, and gallery views.

Command with the down arrow opens a selected folder or file. Command with the up arrow goes to the enclosing folder. Space — just space — gives you Quick Look, which is an instant preview of any selected file. This is one of those features that nobody mentions and everybody loves once they discover it. It previews PDFs, images, video, audio, code, and most office documents instantly, without opening the parent app. Select several files and press Space to flip through them.

Shift Command dot toggles hidden files. Command Delete moves a file to the Trash. Shift Command Delete empties the Trash. After a Command C copy, you can use Option Command V to "move" instead of paste, which deletes the original. And Shift Command G opens a "Go to folder" prompt where you can type any path, including tilde for your home directory. Type tilde slash Library to get into your user library, which is hidden by default, or slash etc to peek at system config files.

Now let's talk about the System Settings worth changing on day one. Open System Settings from the Apple menu and work through these. Under Trackpad — or Mouse, if you have a desktop Mac — turn on "Tap to click", so you don't have to physically depress the trackpad to click. While you are there, check the tracking speed; the default is conservative.

Under Keyboard, set Key Repeat to fast and Delay Until Repeat to short. The defaults make holding down arrow keys feel sluggish. Also enable full keyboard access under Keyboard Navigation, which lets you tab through buttons in dialog boxes.

Under Dock and Menu Bar, shrink the Dock, enable "Automatically hide and show the Dock" if you want the screen real estate back, and turn off "Show recent applications in Dock" if you find that clutter unhelpful. While you are here, scroll down to Hot Corners. Hot Corners are an underused gem. Assign each corner of the screen to a quick action — for instance, bottom-left to Mission Control, top-right to lock screen, top-left to show desktop. Slamming the cursor into a corner is faster than any shortcut.

Under Privacy and Security, turn on FileVault. FileVault encrypts your entire disk with your login password. If the laptop is ever lost or stolen, your files stay unreadable. There is essentially no downside on modern Macs — the encryption is hardware-accelerated.

Still under Privacy and Security, scroll down to Analytics and Improvements. If you'd rather not send usage data to Apple, turn off "Share Mac Analytics" and "Improve Siri and Dictation". That one is personal preference.

Under General, find Time Machine. Plug in an external drive and let Time Machine back up to it. Versioned snapshots every hour, with no thought required, are a quiet superpower the first time you accidentally delete something important.

A couple of optional tweaks. Under Accessibility, Display, there is "Reduce motion". The big sweeping desktop-switch and Mission Control animations look slick but eat real time over the course of a day. Reducing motion makes them snap. And if you are on a laptop, under Battery, set Low Power Mode to kick in automatically when on battery. Modern Macs lose almost nothing in real-world performance and gain meaningful battery life.

Let me pull all of this together with a short workflow. Once these pieces are in your hands, the loop looks like this. You hit Command Space, type two or three letters, hit Return, and your app is open. You press Fn Control Left Arrow to tile it to the left half of the screen, then Command Tab to bring the next app over and tile it to the right. If you have lost a window somewhere, four-finger swipe up to peek at Mission Control. In Finder, you press Space to preview a file before bothering to open it. Shift Command 5 when you need to capture or record something. And Control Command Q to lock the screen when you walk away. None of these is a power-user trick. They are just the standard macOS controls, used the way they were designed to be used. Spend a week deliberately reaching for them and they become reflex.

One last tip. Under System Settings, Keyboard, Keyboard Shortcuts, you can see — and rebind — every shortcut macOS knows about, including per-app menu shortcuts. And inside any app, the Help menu has a search box that finds menu items by name and shows their shortcut next to them. Type half a command and macOS will tell you which menu it lives in and what the keystroke is. Whenever you find yourself reaching for the menu with the mouse, glance at the shortcut next to the item you clicked. That is how the inventory of shortcuts in your head grows.
